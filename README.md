## Apa itu TABRANIJ?

**TABRANIJ** = susunan kode yang memudahkan baca grafik (hafalan visual & bilingual).

**TARI (titik):** Tinggi · Awal · Rendah · Inti  
**Rentang:** Atas · Neto · Bawah · Julat  
**Identitas:** `Julat = Atas + Neto + Bawah` · **Bias:** `I ≷ Awal`
