TABRANIJ Pro v3.1 (TARI)

Loader di repo sedang diperbaiki. Sementara pakai file tunggal dari chat Grok.

Cara benar:
  1. Download file tabranij-pro-v31.html dari pesan Grok
  2. Simpan di folder mana saja
  3. Jalankan: 
    python3 -m http.server 8080
  4. Buka http://localhost:8080/tabranij-pro-v31.html

Atau double-click file HTML (biasanya tetap jalan).

Isi tool:
  • Titik TARI: Tinggi, Awal, Rendah, Inti
  • Rentang: Atas, Neto, Bawah, Julat (+ overlay angka)
  • Multi-candle, timeframe, preset, history

Buku pegangan tetap di folder docs/.
