# Tabranij Visualizer

Tool interaktif 3D untuk visualisasi metode GT (Grafik Tabranij).

## Rencana Pengembangan

Versi selanjutnya akan jauh lebih canggih dari kode dasar, meliputi:

- UI/UX modern & responsif
- Visualisasi 3D yang lebih detail
- Multiple timeframe support
- Export gambar & data
- Mode analisa lanjutan
- Integrasi preset market nyata

## Status

Folder ini disiapkan untuk menampung versi tool yang akan dikembangkan.
