# Bab 11 — Checklist Harian Grup

> Disiplin harian > “setup sempurna” sekali sebulan.

---

## 11.1 Sebelum market (pre-session)

- [ ] Baca bias & struktur **HTF** (D1/H4) — satu kalimat  
- [ ] Tandai level T/R penting (support/resistance)  
- [ ] Tentukan instrumen yang boleh ditrade hari ini (maksimal, jangan semua)  
- [ ] Tetapkan **% risiko per trade** & batas loss harian  
- [ ] Cek berita/sesi yang bisa melebarkan Julat (jika relevan grup)  
- [ ] Kondisi diri: cukup istirahat, tidak memaksa “balas dendam” loss kemarin

**Output:** 2–5 baris rencana harian di jurnal / chat grup.

---

## 11.2 Saat sesi (in-session)

Untuk **setiap** ide trade:

- [ ] Konteks HTF masih valid?  
- [ ] Zona MTF jelas?  
- [ ] Trigger LTF dengan TARI tertulis (minimal Awal, I, T/R invalidation)?  
- [ ] Entry / SL / TP1 tertulis sebelum order?  
- [ ] Size dihitung dari jarak SL (Bab 8)?  
- [ ] RR ≥ ambang grup?  
- [ ] Total risiko terbuka hari ini masih di bawah batas?

Jika satu saja “tidak” tanpa alasan tertulis → **skip**.

---

## 11.3 Setelah trade (post-trade)

- [ ] Jurnal: TARI trigger + hasil dalam R  
- [ ] Apakah SL/TP dihormati?  
- [ ] Satu pelajaran (benar / salah)  
- [ ] Jangan langsung buka trade baru hanya karena emosi hasil trade terakhir

---

## 11.4 Akhir hari (post-session)

- [ ] Hitung total R hari ini  
- [ ] Jumlah trade vs rencana  
- [ ] Pelanggaran SOP (jika ada) dicatat jujur  
- [ ] Screenshot 1 case terbaik / terburuk (opsional → `contoh/`)  
- [ ] Rencana kasar untuk sesi berikutnya  
- [ ] Tutup platform jika batas loss harian tercapai

---

## 11.5 Checklist mingguan (ringkas)

- [ ] Review 5–10 trade: pola error berulang?  
- [ ] Winrate bukan tujuan utama — **proses** (checklist terpenuhi?)  
- [ ] Apakah sering melawan HTF tanpa label counter-trend?  
- [ ] Apakah size konsisten dengan % risiko?  
- [ ] Update level HTF utama untuk minggu depan

---

## 11.6 Aturan “merah” (stop trading hari itu)

Berhenti sejenak / sehari jika:

| Kondisi | Alasan |
|---------|--------|
| 3 loss beruntun | Lindungi modal & emosi |
| Batas loss harian tersentuh | SOP risiko |
| Melanggar SL 2× | Disiplin putus |
| Revenge entry | Proses sudah tidak objektif |
| Kondisi fisik/mental buruk | Edge hilang |

---

## 11.7 Template chat singkat grup

**Pagi**

```text
HTF: …
Level: …
Fokus pair: …
Risiko/trade: …% | Max loss hari: …%
```

**Ide trade**

```text
[Pair] [TF] arah …
Zona … | Trigger …
Entry … SL … TP1 … | RR … | Risk …%
```

**Malas**

```text
Total R: … | Trade: … | Pelanggaran: … | Note: …
```

---

## 11.8 Satu halaman — cetak / pin

```text
PRE   : HTF · level · risiko · kondisi diri
IDE   : konteks · zona · trigger TARI · SL · TP · size
POST  : jurnal R · pelajaran
STOP  : 3 loss / max daily / revenge
```
