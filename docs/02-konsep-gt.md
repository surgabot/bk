# Bab 2 — Konsep Metode GT (Grafik Tabranij)

> Penjelasan mendalam mengenai parameter dan logika metode GT.

## Parameter Utama

| Kode | Nama   | Keterangan                    |
|------|--------|-------------------------------|
| T    | Tinggi | Titik tertinggi               |
| A    | Awal   | Harga awal / open             |
| R    | Rendah | Titik terendah                |
| I    | Inti   | Titik inti (core)             |
| N    | Neto   | Nilai neto (2×Inti − Awal)    |
| J    | Julat  | Range (Tinggi − Rendah)       |
